# RAG-Lab v1.21 — Plan de implementación: Benchmark E2E + RAGAS

> **Estado:** Plan, no implementación. Cada fase requiere confirmación explícita del usuario antes de pasar a la siguiente.

---

## Objetivo

Construir una **prueba empírica y reproducible** de la fiabilidad y precisión de RAG-Lab,
en dos capas separadas:

1. **Capa 1 — Benchmark E2E propio (sin dependencias externas).**
   Captura `pregunta → contextos recuperados → respuesta generada → citas → trust_score`
   para cada query, en un formato JSONL reproducible y versionable.

2. **Capa 2 — Evaluación con RAGAS (en entorno aislado).**
   Consume el JSONL de la capa 1 y produce métricas estándar
   (`faithfulness`, `answer_relevancy`, opcionalmente `context_recall`, `answer_correctness`).

Las dos capas **se comunican solo por archivos** — no comparten entorno Python.
Esto evita que las dependencias de RAGAS (langchain, etc.) contaminen el entorno `rag-lab`.

---

## Filosofía

Aplicamos las mismas reglas que el ROADMAP:

- **No añadir features por inercia.** El benchmark E2E es observacional — **no modifica el pipeline de retrieval**.
- **Aislamiento estricto.** RAGAS vive en un conda env separado (`ragas`). El env `rag-lab` no se toca.
- **Pasos pequeños con confirmación.** Entre fases, el agente debe parar y esperar OK del usuario.
- **Fallback explícito.** Si una fase falla, el plan dice qué hacer antes de seguir.
- **Juez externo desde el principio.** El LLM-as-judge es **DeepSeek vía OpenRouter** — distinto al generador local (Qwen3.6-27B). Esto elimina el self-preference bias y hace el resultado publicable sin caveat.

---

## Configuración del LLM-as-judge (decisión global)

Esta es la decisión única que aplica a todas las fases que usan RAGAS:

- **Provider:** [OpenRouter](https://openrouter.ai/) (API OpenAI-compatible).
- **Modelo:** DeepSeek vía OpenRouter. **El slug exacto del modelo lo confirma el usuario en F3** (las opciones razonables son `deepseek/deepseek-chat-v3-0324`, `deepseek/deepseek-r1`, o `deepseek/deepseek-chat` — el agente debe preguntar antes de ejecutar).
- **Base URL:** `https://openrouter.ai/api/v1`
- **Autenticación:** API key en variable de entorno `OPENROUTER_API_KEY`, **nunca commiteada al repo**.
- **Coste estimado:** 65 queries × 2 métricas × ~3 LLM calls/métrica × precio DeepSeek (≈ $0.0001 por 1K input tokens) → ~$0.20-0.50 por corrida completa. Despreciable.
- **Por qué no juez local:** el mismo Qwen-27B genera Y juzga → self-preference bias documentado en la literatura (modelos puntúan más alto sus propias respuestas). Para que el reporte sea publicable, juez ≠ generador.

#### F3.3.c — Crear `tools/ragas/config.py`

```python
"""LLM-as-judge configuration for RAGAS evaluation.

Reads OpenRouter credentials from environment. Never log or print the API key.
"""
import os
from langchain_openai import ChatOpenAI


def get_judge_llm() -> ChatOpenAI:
    """Returns the OpenRouter-backed judge LLM (DeepSeek by default)."""
    api_key = os.environ.get("OPENROUTER_API_KEY")
    model = os.environ.get("OPENROUTER_JUDGE_MODEL", "deepseek/deepseek-chat-v3-0324")
    if not api_key:
        raise RuntimeError(
            "OPENROUTER_API_KEY not set. Add it to .env or export it. "
            "Get a key at https://openrouter.ai/keys"
        )
    return ChatOpenAI(
        base_url="https://openrouter.ai/api/v1",
        api_key=api_key,
        model=model,
        temperature=0,
        default_headers={
            # OpenRouter usa estos headers solo para analytics — opcionales:
            "HTTP-Referer": "https://github.com/ajujo/raglab-local",
            "X-Title": "RAG-Lab evaluation",
        },
    )
```

### F3.5 — Script smoke test

Crear `tools/ragas/smoke_test.py`:

```python
"""Smoke test RAGAS — 1 métrica sobre 5 queries.

Ejecutar desde el env `ragas`:
    conda activate ragas
    python tools/ragas/smoke_test.py --input /tmp/ragas_smoke_5.jsonl
"""
import argparse, json, sys
from pathlib import Path
from datasets import Dataset
from ragas import evaluate
from ragas.metrics import faithfulness
from tools.ragas.config import get_judge_llm


def load_jsonl(path: Path) -> Dataset:
    rows = [json.loads(l) for l in path.read_text().splitlines() if l.strip()]
    # Mapear schema de F1 al schema de RAGAS
    return Dataset.from_list([
        {
            "question": r["question"],
            "answer": r["answer"],
            "contexts": r["contexts"],
        }
        for r in rows
    ])


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--input", required=True, type=Path)
    args = p.parse_args()

    ds = load_jsonl(args.input)
    print(f"Loaded {len(ds)} samples")

    judge = get_judge_llm()
    result = evaluate(ds, metrics=[faithfulness], llm=judge)
    print("\n=== RAGAS smoke test result ===")
    print(result)
    df = result.to_pandas()
    print(df[["question", "faithfulness"]])

    # Sanity checks
    values = df["faithfulness"].tolist()
    assert len(values) == 5, f"Expected 5 results, got {len(values)}"
    assert all(0.0 <= v <= 1.0 or v != v for v in values), f"Values out of [0,1]: {values}"
    print("\n✓ Smoke test PASS")


if __name__ == "__main__":
    main()
```
