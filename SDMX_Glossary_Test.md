# Documento de Prueba SDMX — Glossario y Referencias

## 1. Definiciones Básicas

SDMX (Statistical Data and Metadata eXchange) es un conjunto de estándares para el intercambio de datos estadísticos y metadatos.

### 1.1 Componentes Principales

- **SDMX-ML**: Formato basado en XML para intercambio de datos.
- **SDMX-EDI**: Formato basado en EDIFACT para intercambio de datos.
- **DSD (Data Structure Definition)**: Define la estructura de los conjuntos de datos.
- **SDMX-IM**: Modelo de información de SDMX.

## 2. Formatos de Intercambio

Los estándares de formato de SDMX están diseñados para permitir el intercambio eficiente de datos estadísticos entre organizaciones.

### 2.1 SDMX-ML

SDMX-ML utiliza XML como formato subyacente. Permite la representación estructurada de datos y metadatos.

### 2.2 SDMX-EDI

SDMX-EDI utiliza el formato EDIFACT/GESMES/TS como base. Es más compacto que SDMX-ML pero con menor expresividad.

## 3. Casos de Uso

- Intercambio de datos entre oficinas nacionales de estadística.
- Publicación de datos abiertos.
- Integración de sistemas de información estadística.
